# Keyboard Bindings

On Windows/Linux, ⌘ = Ctrl. All other bindings are identical.

## Global Commands

These work while WorkBound is not focused.

> (ac) = Requires macOS Accessibility permission (System Settings → Privacy & Security → Accessibility).

| Key     | Action                |
| ------- | --------------------- |
| ⌘ ⌥ W   | Show WorkBound (ac)   |
| ⌘ ⇧ 3   | Show WorkBound (ac)   |
