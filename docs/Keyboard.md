# Keyboard Bindings

On Windows/Linux, ⌘ = Ctrl. All other bindings are identical.

## Shell

| Key | Action |
| --- | ------ |
| ↑ / ↓ | Move through mail list |
| Enter | Open email |
| Esc | Clear selection |
| ⌘K | Command palette |
| `/` | Search |
| c | New message |
| s | Settings |
| f | Toggle filters |
| r | Check for mail |
| i n | Inbox |
| d r | Drafts |
| b i | Bin |
| s e | Sent |
| s p | Spam |

## List row selected

| Key | Action |
| --- | ------ |
| s | Toggle star |
| r | Mark read |
| u | Mark unread |
| b | Block sender |
| e | Archive |
| i | Toggle important |
| ! / ! ! | Spam / Phishing |
| Del / ⌫ | Delete |

| s | Toggle star |
| i | Toggle important |
| u | Mark unread |
| b | Block sender |
| e | Archive |
| ! / ! ! | Spam / Phishing |

## Composer

| Key | Action |
| --- | ------ |
| ⌘S | Send |
| ⌘L | Send later |
| ⌘@ | Attach |
| ⌘D | Discard draft |
| ⌘U | Undo send |
| Esc | Save & close |
